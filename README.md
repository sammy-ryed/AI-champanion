# AI Storyteller

An interactive AI-powered storytelling experience that engages children through visual prompts and voice conversation.

## Features

- Visual storytelling with engaging images
- Real-time voice interaction
- AI-driven conversation that adapts to user responses
- Interactive UI elements

## Setup

```bash
npm install
npm run dev
```

## Tech Stack

- React + Vite
- OpenAI API
- Web Audio APIs
